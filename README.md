Вариант 14

Задание 1 — блок-схема «Доставка с двумя правилами» (2 балла). Обычная доставка 10; при массе больше 10 кг добавляется 8; при заказе от 100 доставка полностью бесплатна.

Задание 2 — программа (2 балла). Считать радиус сферы. Используя const PI, вывести площадь поверхности 4 * PI * r * r.

Задание 3 — программа повышенного уровня (4 балла). Считать два целых a, b и символ операции (+, -, *, /, %). Для / и % обязательно проверить b != 0. Для неизвестной операции вывести сообщение.
